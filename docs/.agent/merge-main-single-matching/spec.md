# main と single-matching の統合仕様

## 対象

`main` のスキャン・校正・ターンテーブル機能と `feature/single-matching` のホーム画面マッチング導線を統合する。統合後のマッチング導線は、開発者設定で選択したプロジェクターモニターと左右カメラで撮影し、既存の固定参照 PLY と撮影した対象 PLY を `3mserve` の `matching` モードで照合する。

## 制約

- スキャン出力は既存ターゲットを直接上書きしない。ターゲット親ディレクトリ内に専用権限の一時ディレクトリを確保し、未作成の `cloud.ply` に保存する。応答と完了イベント、返却パス、非 symlink の通常 PLY と正の頂点数を検証した後、アプリ側で単一の rename により置換する。
- スキャンまたは照合中の重複処理を拒否する。失敗・タイムアウト・サイドカー終了時に一時ファイルを残さず、既存ターゲットをスキャン成功前に変更しない。
- ホーム画面の照合元は常に設定済み `matchingSourcePath` とする（固定参照設定では上書きしない）。main の `/scan` 系処理は `fixedReferencePly` が明示されていればそれを照合元とし、未設定なら `matchingSourcePath` にフォールバックする。`matchingTargetPath` は参照 PLY として使用しない。ホームの出力ターゲットが照合元、`matchingSourcePath`、または `fixedReferencePly` と同一・alias の場合、撮影前と公開直前の両方で実行を拒否する。
- core-tools のプロトコル・実装は変更しない。3D マッチングは `matching` モードのみ使用する。
- ホーム画面の既存デザインを維持し、マッチング開始ボタンはストリーム操作の直前に置く。校正導線は追加しない。
- main の `/scan` ルートとスキャン関連機能を保持する。

## 設定

main のスキャン設定と `feature/single-matching` のプロジェクターモニター設定を併存させる。既存の設定 JSON は後方互換で読み込み、未設定の任意値は既定値として扱う。
